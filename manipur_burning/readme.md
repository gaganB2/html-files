# MANIPUR — A Living Documentary

A cinematic, scroll-driven documentary prototype about the 2023 Manipur violence, built to explore **digital storytelling, visual hierarchy, and interactive frontend experiences**.

### 🔗 Live Demo

https://violence.gagansahu55428.workers.dev/

### Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Three.js / WebGL
- Intersection Observer

### Highlights

- Scroll-based chapter navigation and progress indicator
- Responsive desktop and mobile experience
- Three.js particle/ember background
- CSS-based smoke, grain, glow and atmospheric effects
- Interactive glass cards with mouse tilt
- Section reveal animations using `IntersectionObserver`
- Reduced-motion support and CSS fallback for Three.js

### Approach

I'm intermediate with JavaScript and built this primarily as a **frontend prototyping and digital storytelling exercise**.

Three.js was new to me, so I explored it mainly as a tool for creating a richer visual atmosphere rather than as the core of the application.

The main question behind the project was:

> **How can a serious story be experienced, rather than simply read?**

**Status:** Experimental frontend prototype / personal project
