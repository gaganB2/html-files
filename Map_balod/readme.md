### Interactive Balod District Map

Built a responsive interactive map for **Balod, Chhattisgarh** featuring:

- Interactive **roads, satellite & humanitarian map layers**
- Custom **GeoJSON district boundary** with hover effects
- Map controls, markers, popups & responsive UI
- Glassmorphism-style interface with mobile support
- Built using **HTML, CSS, JavaScript & Leaflet.js**
