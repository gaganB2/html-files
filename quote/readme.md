### ☁️ Sky Quote | HTML, CSS, JavaScript

Built a responsive motivational quote web app featuring:

- Dynamic quotes fetched from a **REST API**
- Responsive **glassmorphism UI** with animated clouds, particles & sun
- Interactive **3D card parallax** effect
- API error handling with a fallback quote
- Mobile-friendly design with **reduced-motion support**
